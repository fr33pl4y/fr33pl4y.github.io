Installation:


  1. Step 1. Windows/macOS/Linux: Install Microsoft .NET SDK
  2. Step 2. Install MonoGame Project Templates (open a Terminal):

    dotnet new install MonoGame.Templates.CSharp
  3. Step 3. Install the MGCB Editor (open a Terminal):

    dotnet tool install --global dotnet-mgcb-editor
    mgcb-editor --register

Create and Run a New MonoGame Project:


  1. Step 1. Create a new directory and scaffold the project:

    dotnet new mgdesktopgl -o MyMonoGameGame
  2. Step 2. Navigate into the project folder:

    cd MyMonoGameGame
  3. Step 3. Build and run the game:

    dotnet run
